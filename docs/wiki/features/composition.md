# Composition contract

The root accepts semantic input events: Character, SpaceBoundary, PunctuationBoundary, CaretMoveBoundary, ShortcutBoundary, CompositionControl, RawBoundary and Lifecycle. It changes root state before synchronously emitting RootTransition to the selected language FSM.

Language-specific FSMs own text interpretation. Space and punctuation are distinct root states and invoke the language's boundary policy before the original delimiter is emitted. Navigation/mouse and shortcuts commit the displayed composition before the original host input proceeds. AltGraph remains character input. Backspace/Escape control composition; Shift+Space behaves as ordinary Space when displayed equals raw, and otherwise commits raw physical input once without inserting Space. Lifecycle events terminate/reset the active context.

Vietnamese supports Telex, Simple Telex and VNI, plus modifier reordering correction at word boundaries without inventing tone input. Live typing remains sequential and explicit repeat-cancel remains immediate. Tests and the current behavioral overview are in [README](../../../README.md), `Bootstrap/Runtime/tests/vietnamese_regression.rs`, and the language FSM implementation. Any changed semantic event requires core, host adapter and language-pack compatibility verification together.

English lexicon hits while a Vietnamese candidate remains viable are provisional display choices, never an irreversible raw lock. A completed Telex interpretation wins if it preserves physical base-letter order and passes the Vietnamese syllable validator, with or without a tone (`barn` -> `bản`, `dud` -> `đu`, `dudowcj` -> `được`). The validator enforces onset spelling (c/k, g/gh, ng/ngh), onset/rime cooccurrence including rounded offglides after the `qu` medial, vowel/coda compatibility, and checked-tone restrictions. Speculative `quêu` is rejected structurally, so `queue` remains raw without an English dictionary. Modifiers may move; base letters never arbitrarily permute. Space/punctuation share the decision, but explicit literal cancellation and RawBoundary are authoritative. Equal-ranked ambiguous parses are not guessed. Phonotactic validity is not proof that every possible syllable is an attested word; proper nouns, rare words and context remain outside this parser. No third-party Vietnamese word list is embedded or required.
