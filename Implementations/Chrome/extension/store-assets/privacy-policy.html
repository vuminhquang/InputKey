Privacy Policy — InputKey

Effective date: September 21, 2026

InputKey provides Vietnamese Telex and VNI typing inside editable fields on websites.

Data processed

The extension processes keystrokes and the current word in the editable field only as needed to convert Telex or VNI sequences into Vietnamese text. This processing happens locally in browser memory.

Data collection and transmission

The extension does not collect, store, sell, share, or transmit the text you type, browsing history, page contents, personal information, authentication information, financial information, health information, or location data. It contains no analytics, advertising SDKs, tracking code, or remote code.

Local preferences

The extension stores only its settings—such as enabled/disabled state, Telex or VNI selection, Simple Telex, auto-restore, and toast preference—using chrome.storage.local. These preferences remain in the local Chrome profile and are not sent to a developer-operated server.

Website access

The extension runs on normal HTTP and HTTPS pages so it can detect typing in editable fields and provide Vietnamese input. It ignores password fields and does not use page access for advertising, profiling, analytics, or unrelated purposes.

Third parties

No typed content or browsing data is shared with third parties. The extension does not operate a backend service.

Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Changes

If the extension's data practices change, this policy will be updated before the changed behavior is released.
