InputKey

Gõ tiếng Việt trong Chrome · Telex / VNI

Nhấn lặp phím dấu để hủy: gõ docss → docs; pass → pas; passs → pass. Các từ password, coffee vẫn được giữ nguyên.

Hoàn tác dấu của từ
refer → rể → phím tắt → refer
Phím tắt: Ctrl + Shift hoặc Alt + Z
Telex: aa → â · aw → ă · dd → đ · s/f/r/x/j → dấu thanh
VNI: 6/7/8/9 → dấu chữ · 1–5 → dấu thanh
Ô thử chạy trực tiếp bằng engine của extension.
