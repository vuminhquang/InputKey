Privacy Policy — InputKey

Last updated: October 16, 2026

InputKey is a local-first multilingual input extension for Vietnamese (Telex/VNI), French, Danish, Swedish and German (Telex). Official website: InputKey.

Data processed

The extension processes physical key events and the current word only as necessary to provide input in the selected language. This happens locally in your browser's memory. Password fields are ignored.

Data collection and transmission

InputKey does not collect, retain or transmit typed text, page contents, browsing history, personal information, authentication data, financial information, health information or location data to the developer. It contains no advertising SDKs, analytics, telemetry, tracking or remotely hosted executable code. There is no developer-operated typing backend.

Local preferences

The extension stores its enabled state, language, method, optional typing features, shortcut and interface preferences in chrome.storage.local. These preferences remain in the local browser profile and are not sent to a developer-operated service.

Website access

InputKey runs on ordinary HTTP and HTTPS pages to process typing in editable fields across websites. It does not use that permission for profiling, advertising or unrelated activities and does not run on protected browser pages.

Third parties

Typed content and browsing data are not sold, shared or sent to third parties by InputKey.

Limited Use

The use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements.

Changes

Any future change to data practices will be reflected in this policy before the changed extension is released.
